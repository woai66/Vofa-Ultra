# 路线图

路线图以可靠性门槛而不是日期驱动。只有前一阶段的行为、测试和迁移路径稳定后，才进入下一阶段。

## v0.1 - 串口工作台基础

已实现：

- [x] Tauri 2 + Rust 串口枚举、连接、断开和参数配置
- [x] 有界 TX 队列、分块公平写入、状态 revision 与可诊断错误
- [x] 文本 / HEX 收发、行尾、统计和日志导出
- [x] FireWater、JustFloat、Raw Data
- [x] 16 通道有界波形与 800 条虚拟终端
- [x] 模拟数据源、明暗主题和窄屏布局
- [x] 单元、组件和浏览器端到端测试
- [x] 最小 Tauri capability、严格 CSP 和开源项目文档

发布前门槛：

- [x] 在 Windows 完成首次 Rust 构建与测试并提交 `Cargo.lock`
- [x] 在 macOS、Linux CI 中验证锁定依赖的 Rust 构建与测试
- [x] 开启 Tauri bundle，配置三平台无签名候选安装包与 SHA-256 流水线
- [ ] 在 GitHub Actions 首次实际生成并核验三平台候选安装包
- [ ] 在 Windows、macOS、Linux 完成候选包安装、启动和卸载冒烟测试
- [ ] 在 Windows 上完成至少两种 USB 串口芯片的连接、收发、拔插和重连验证
- [ ] 验证软件流控、硬件流控以及 DTR / RTS 行为

## v0.2 - 采集、记录与回放

已实现：

- [x] 命名工作区保存、应用、另存、删除和 JSON 导入导出
- [x] 严格的工作区 v2 schema、v0/v1 迁移、未来版本只读保护和浏览器串口降级
- [x] 工作区切换前安全断开、运行缓存清理、通道显隐恢复和未保存确认
- [x] `.vucap` v1 原始 RX / TX 文件格式、流式 reader 和异常文件检测
- [x] Rust 独立 writer、按字节有界背压、模拟器有界 IPC 队列和录制生命周期收尾
- [x] `.vucap` v1 流式扫描、完整性提示和有界 ACK 背压的历史回放
- [x] 回放播放、暂停、继续、停止、重播、关闭，以及实时连接和工作区生命周期互锁
- [x] `0.25× / 0.5× / 1× / 2× / 4×` 有界倍速、播放中连续切速和会话生命周期重置
- [x] Raw Data 时间轴 seek、2 MiB 自压缩稀疏索引、异步定位与代次隔离
- [x] FireWater / JustFloat 协议同步点 seek、record 内偏移和实际吸附位置反馈
- [x] 强 USB 身份自动重连、有界退避、全阶段取消、代次隔离和脱敏诊断导出
- [x] CSV / JSONL / 单向二进制流式导出、方向过滤、进度取消和失败恢复
- [x] 波形双游标采样吸附、时间/频率/幅值差测量和视图生命周期隔离

计划中：

- [ ] 持久时间线标记及兼容 VUCAP v1 reader 的 `.vucap` 格式升级

验收重点：持续采集 8 小时后内存保持在约定上限内；强制拔插不会产生僵死 worker 或错误状态倒退。

## v0.3 - 协议与自动化

已实现：

- [x] 文档化的仓库内置增量协议注册表、合规夹具和贡献模板
- [x] 会话级命令历史，连续重复归并、100 条和 256 KiB payload 双上限
- [x] 有限次数或持续周期发送，单在途调度、显式停止、代次隔离和生命周期取消
- [x] 任务输入冻结、20 ms 到 24 小时参数边界、失败停机和模拟器端到端验收
- [x] 安全命令变量、TEXT / HEX 定宽编码、资源上限和逐次时间/序号语义
- [x] 可选的有界数据处理 DAG、列表式编辑器、独立派生通道和工作区 v2 往返
- [x] 实时/回放滤波状态隔离、暂停期间状态推进、预算熔断和基础链路故障隔离

计划中：

- [ ] 基础/派生数值通道的有界实时 CSV 记录，不依赖处理图
- [ ] 定义姿态通道、单位和坐标系映射后提供 3D 姿态视图
- [ ] 第三方扩展采用隔离执行与显式能力授权，不在主 WebView 动态执行代码

验收重点：损坏、超长和随机分包输入不会导致无界内存、主线程阻塞或权限升级。

## v1.0 - 可持续发布

- Windows、macOS、Linux 签名安装包和校验值。
- 受保护的发布环境、可复现构建记录、SBOM 和依赖许可证清单。
- 配置兼容性承诺、稳定协议 API 和弃用策略。
- 完整用户手册、故障排查矩阵和硬件兼容性清单。
- 性能基准与回归阈值进入 CI。
