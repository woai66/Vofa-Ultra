# 路线图

路线图以可靠性门槛而不是日期驱动。只有前一阶段的行为、测试和迁移路径稳定后，才进入下一阶段。

## v0.1 - 串口工作台基础

已实现：

- [x] Tauri 2 + Rust 串口枚举、前台静默刷新、脱敏设备摘要、连接、断开、参数配置、在线 DTR / RTS 控制，
  以及 CTS / DSR / RI / DCD 三态监视
- [x] 有界 TX 队列、分块公平写入、状态 revision 与可诊断错误
- [x] 文本 / HEX 收发、TX 行尾、按读取块/文本行记录的 RX 终端、可选接收行尾与文本编码、有界残行、统计，
  以及全部缓存/当前筛选视图日志导出
- [x] FireWater、JustFloat、Raw Data
- [x] 16 通道有界波形、共享/独立自动量程、固定 Y 量程、框选挂起跟随与回到实时，以及支持三种时间基准、搜索、
  方向过滤、上滚挂起跟随和回到最新的 800 条虚拟终端
- [x] 基础、派生与扩展通道的有界实时监视、最近 256 点统计、本地冻结和响应式紧凑表格
- [x] 十类可复现模拟信号、1–16 通道、五档采样率、明暗主题和窄屏布局
- [x] 单元、组件和浏览器端到端测试
- [x] 最小 Tauri capability、严格 CSP 和开源项目文档

发布前门槛：

- [x] 在 Windows 完成首次 Rust 构建与测试并提交 `Cargo.lock`
- [ ] 在 macOS、Linux 上人工验证锁定依赖的 Rust 构建与测试
- [x] 提供 Tauri 三平台无签名候选安装包与 SHA-256 的本地命令
- [ ] 项目稳定后再评估最小化的 GitHub Actions 检查
- [ ] 在 Windows、macOS、Linux 完成候选包安装、启动和卸载冒烟测试
- [ ] 在 Windows 上完成至少两种 USB 串口芯片的连接、收发、拔插和重连验证
- [ ] 验证软件流控、硬件流控以及 DTR / RTS / CTS / DSR / RI / DCD 行为

## v0.2 - 采集、记录与回放

已实现：

- [x] 命名工作区保存、应用、另存、删除和 JSON 导入导出
- [x] 严格的工作区 v12 schema、v1-v11 导入、本地 v0-v11 迁移、未来版本只读保护和浏览器串口降级
- [x] FireWater / JustFloat 基础通道别名、单位与颜色的协议隔离、展示投影和数据契约保护
- [x] 工作区切换前安全断开、运行缓存清理、通道显隐恢复和未保存确认
- [x] `.vucap` v1 原始 RX / TX 格式、VUCAP v2 writer、v1/v2 reader 和异常文件检测
- [x] Rust 独立 writer、按字节有界背压、模拟器有界 IPC FIFO 和录制生命周期收尾
- [x] 原始捕获与实时数值 CSV 共用的会话级记录目录、后端绝对路径校验和无覆盖文件创建
- [x] `.vucap` v1/v2 流式扫描、完整性提示和有界 ACK 背压的历史回放
- [x] 回放播放、暂停、继续、停止、重播、关闭，以及实时连接和工作区生命周期互锁
- [x] `0.25× / 0.5× / 1× / 2× / 4×` 有界倍速、播放中连续切速和会话生命周期重置
- [x] Raw Data 时间轴 seek、2 MiB 自压缩稀疏索引、异步定位与代次隔离
- [x] FireWater / JustFloat 协议同步点 seek、record 内偏移和实际吸附位置反馈
- [x] 强 USB 身份自动重连、有界退避、全阶段取消、代次隔离和脱敏诊断导出
- [x] CSV / JSONL / 单向二进制流式导出、方向过滤、进度取消和失败恢复
- [x] 波形双游标采样吸附、时间/频率/幅值差测量和视图生命周期隔离
- [x] 波形 A/B 闭区间样本数、极值、均值、RMS 和峰峰值统计
- [x] 基础/派生/扩展通道的 256/512/1024 点频谱、显式采样率、Hann 幅值校正和窄屏布局
- [x] 实时基础/派生通道的上升沿与下降沿单次触发、居中捕获、冻结标线和后台链路隔离
- [x] VUCAP v2 持久命名时间线标记、v1/v2 reader、回放定位和 JSONL 保留

验收重点：持续采集 8 小时后内存保持在约定上限内；强制拔插不会产生僵死 worker 或错误状态倒退。

## v0.3 - 协议与自动化

已实现：

- [x] 文档化的仓库内置增量协议注册表、合规夹具和贡献模板
- [x] 会话级命令历史，连续重复归并、100 条和 256 KiB payload 双上限
- [x] 有限次数或持续周期发送，单在途调度、显式停止、代次隔离和生命周期取消
- [x] 任务输入冻结、20 ms 到 24 小时参数边界、失败停机和模拟器端到端验收
- [x] 安全命令变量、TEXT / HEX 定宽编码、资源上限和逐次时间/序号语义
- [x] ASCII 0..127 快查、控制字符多表示查询和零隐式发送
- [x] 独立 TEXT/HEX 校验快算、标准 CRC 向量、资源上限和零发送状态副作用
- [x] 工作区级自动校验尾、CRC/XOR/SUM 与字节序选择、手动/周期统一构帧和历史模式恢复
- [x] 独立字节/数值互转、明确类型与大小端、严格边界和零发送状态副作用
- [x] 桌面串口原始文件流式发送、显式开始、进度取消、生命周期收尾和发送工作流互斥
- [x] 工作区级命名快捷命令、原始模板保真、显式发送、排序管理和有界持久化
- [x] 常用 Modbus RTU 请求构帧、严格地址/数量/广播边界、CRC16 预览和统一 HEX 发送链路
- [x] Modbus RTU 单事务主站、总线静默、超时/取消、异常响应、结构化结果和连接代次隔离
- [x] Modbus RTU `01/02/03/04` 有界只读轮询、单在途调度、终态后固定间隔、错误停机和会话态结果
- [x] 有界 RX 自动应答、跨 chunk 字节匹配、冷却/队列/会话上限、手动优先与回放旁路
- [x] FireWater / JustFloat 有界解析健康度、稳定丢帧原因、流边界重置和实时/回放隔离
- [x] 可选的有界数据处理 DAG、列表式编辑器、独立派生通道和当前工作区 schema 往返
- [x] 缩放、移动平均与 U16 小端解码固定预设，原子展开现有节点且不增加工作区 schema
- [x] 处理图帧内字节/数值转换、明确类型与大小端、逐字节输出、同帧约束和非法输入 gap
- [x] 实时/回放滤波状态隔离、暂停期间状态推进、预算熔断和基础链路故障隔离
- [x] 基础/派生数值通道的有界实时 CSV 记录，不依赖处理图
- [x] Euler degrees/radians、Quaternion W/X/Y/Z、ENU/FLU 与 NED/FRD 的帧一致 3D 姿态视图
- [x] 实验性 `.vux` Wasm 实时附加解析器、零 import 解释器边界、会话级 RX 授权和独立故障隔离

计划中：

- [ ] 使用真实 RS-485 适配器验证本地回显、半双工方向切换、响应时序和取消后的写入语义
- [ ] 单事务、只读轮询和硬件语义稳定后，再独立评估寄存器地图、受控重试和 Modbus TCP
- [ ] 评估只读调试器 Live Watch 数据源；先固定 ELF 类型、探针授权、有界采样、时间戳和进程隔离，再决定
  provider ABI 与 AI MCP 边界
- [ ] 基于真实扩展反馈稳定 ABI，并设计发布者身份、签名/撤销、来源和完整许可证材料
- [ ] 评估可替换内置 parser、回放解析和处理链集成；在数据语义明确前保持 v1 仅实时、附加、仅显示
- [ ] 若风险模型需要更强隔离，评估独立 OS 进程 worker，而不是把进程内 Wasmi 限制描述为完整沙箱

验收重点：损坏、超长和随机分包输入不会导致无界内存、主线程阻塞或权限升级。
