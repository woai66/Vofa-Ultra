# 安全命令模板

命令模板用于给手动发送和周期发送加入可预测的序号与时间字段。它只做一次白名单变量替换，不执行 JavaScript、
Wasm、Shell 或用户表达式，也不读取环境、文件、网络、接收数据和通道状态。

## TEXT 变量

| 变量 | 输出 |
| --- | --- |
| `${seq}` | 从 1 开始的十进制发送序号 |
| `${unix_ms}` | 本次派发的 Unix 毫秒整数 |
| `${unix_s}` | 本次派发的 Unix 秒整数，向下取整 |
| `${iso_utc}` | 本次派发时间的 ISO-8601 UTC 文本 |
| `${task_unix_ms}` | 周期任务启动时冻结的 Unix 毫秒整数 |

TEXT 中 `$$` 输出一个字面量 `$`，因此 `$${seq}` 会发送 `${seq}`，不会再次解释变量。

```text
SET,channel=2,sequence=${seq},time=${unix_ms}
```

## HEX 变量

HEX 变量必须显式声明宽度和端序。变量直接产生字节，不会先转成文本再交给 HEX 解析器。

| 变量 | 可用格式 |
| --- | --- |
| `seq` | `u8`、`u16le`、`u16be`、`u32le`、`u32be` |
| `unix_ms` | `u64le`、`u64be` |
| `unix_s` | `u32le`、`u32be`、`u64le`、`u64be` |
| `task_unix_ms` | `u64le`、`u64be` |

例如序号 1 的 `${seq:u16le}` 输出 `01 00`，`${seq:u16be}` 输出 `00 01`。

```text
AA 55 ${seq:u16le} ${unix_ms:u64be} 0D 0A
```

变量两侧的 HEX 字面量分别由现有 HEX 解析器校验，必须各自落在完整字节边界。`A${seq:u8}` 和
`${seq:u8}B` 都会被拒绝；不会猜测半字节应该如何拼接。`iso_utc` 没有二进制定宽格式。

## 调度与历史语义

- 手动发送始终使用 `seq = 1`，本次时间同时作为 `unix_ms` 和 `task_unix_ms` 的上下文。
- 周期任务启动时冻结原始模板、格式、行尾和 `task_unix_ms`，之后编辑输入框不会改变运行任务。
- 周期任务第一次立即使用序号 1；每次成功发送后才推进序号，失败不跳号、不重试、不追赶遗漏周期。
- `unix_ms`、`unix_s` 和 `iso_utc` 在每次派发时共享同一次时间采样。
- 行尾在变量展开后追加，并计入最终发送字节上限。
- 历史保存原始模板；点击历史后重新求值。含变量条目显示最近一次展开长度，实际字节以 TX 终端和 VUCAP 为准。
- 编译、渲染或发送失败都不会写入历史；周期任务的后续渲染失败会保留已有成功计数并进入错误终态。

## 资源与安全边界

| 边界 | 上限 |
| --- | ---: |
| 原始模板 UTF-8 长度 | 256 KiB |
| 单个模板变量数量 | 256 |
| 单个变量 token 长度 | 64 个 UTF-16 code unit |
| 展开内容与行尾合计 | 64 KiB |

扫描器只接受 `${name}` 或 `${name:format}`。未知名称、未知格式、空白、点属性、函数调用、运算符、多冒号、
未闭合或嵌套 token 都会报错。无符号整数在写入定宽字段前核对范围，禁止截断和回绕。

首版明确不支持用户自定义变量、算术、条件、循环、函数、随机数、UUID、CRC、自动应答、端口或环境字段、
RX / 波形 / 通道引用和递归展开。这些能力不能通过放宽当前扫描器加入；需要独立威胁模型、权限边界和任务协议。

## 实现与验证

纯函数实现位于 `src/core/commandTemplate.ts`，调度语义位于 `src/core/commandWorkflow.ts`。Store 只把最终
`Uint8Array` 交给模拟器或 Rust 串口层，后端继续执行权威的 64 KiB 单次发送上限，不解析模板。

修改变量或格式时，至少运行 `pnpm check` 和 `pnpm test:e2e`，并补齐 TEXT、HEX 大小端、错误输入、大小边界、
序号成功后推进、时间采样、历史与零发送失败路径。
